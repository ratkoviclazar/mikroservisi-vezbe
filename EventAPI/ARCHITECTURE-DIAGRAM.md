## Data Flow Diagram

### Creating an Event

```
User (Browser)
    ?
    ? Click "Create Event"
    ?
    ?
EventsProxyController.Create() (GET)
    ?
    ? Return Create.cshtml form
    ?
    ?
User fills form and submits
    ?
    ? POST to EventsProxyController.Create()
    ?
    ?
EventsProxyController.Create(CreateEventDto)
    ?
    ? Call IEventApiClient.CreateEventAsync()
    ?
    ?
HTTP POST to Event Service API (5000)
    ?
    ?
EventsApiController.CreateEvent()
    ?
    ? Call IEventService.CreateEventAsync()
    ?
    ?
EventService.CreateEventAsync()
    ?
    ?? Validate input
    ?? Save to EventDb
    ?
    ?? Publish EventCreatedIntegrationEvent
        ?
        ?
    IEventBusPublisher.PublishAsync()
        ?
        ?? In-Memory (Dev): Log event
        ?
        ?? RabbitMQ (Prod): Send to message queue
            ?
            ?
        Other services listen and react
```

### Fetching Events

```
User (Browser)
    ?
    ? Navigate to /events
    ?
    ?
EventsProxyController.Index() (GET)
    ?
    ? Call IEventApiClient.GetAllEventsAsync()
    ?
    ?
HTTP GET to Event Service API (5000)
    ?
    ?
EventsApiController.GetAllEvents()
    ?
    ? Call IEventService.GetAllEventsAsync()
    ?
    ?
EventService.GetAllEventsAsync()
    ?
    ?? Query database
    ?
    ?? Map to EventDtos
        ?
        ?
    Return List<EventDto> to controller
        ?
        ?
    Return to proxy controller
        ?
        ?
    Return to view
        ?
        ?
    Display in browser (Razor template)
```
